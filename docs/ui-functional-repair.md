- **Clear report:** invalidates current worker and removes current report/history result; retains import account/files/date/confirmation and saved snapshots. Does not delete downloads.
- **Start over:** additionally clears both React and native file selection, form values, filters, selected comparison, and current mode fragment; retains saved snapshots/downloads.
- **Cancel processing:** invalidates/terminates only the current job; preserves previously completed report, import details and saved snapshots. A stale reply cannot overwrite them.
- **Delete saved snapshots:** separate explicit confirmation; clears only this checker-origin IndexedDB store, invalidates its pending comparison; in-memory report/downloads remain.
- Sample route reload regenerates fictional data intentionally. Generic route reload restores no in-memory report. Imported reports require an explicit replacement choice when sample is activated.

## Verification and limitations

Baseline reproduction evidence is in `docs/evidence/repair/before/`; final results and curated images are in `docs/evidence/repair/after/`. Normal browser tests use real module workers and the real local API; fault tests are explicitly named `fault:` and isolate injected failures/delayed delivery.

The installed WebKit engine is not a claim of testing installed Safari. On this macOS host, full keyboard traversal uses Option-Tab in WebKit; Tab alone skips buttons/links per the host setting. The same keyboard assertions run with that native key combination (no system setting changed). Linux CI uses Tab. This behavior was probed directly; see the [upstream report](https://github.com/microsoft/playwright/issues/41808). Local blob reads are accepted only for the checker origin; outbound HTTP and write requests remain rejected by privacy assertions.

Native OS file-picker **Cancel** is not automated; clearing file selection and selecting the same files again are tested. Automated axe and keyboard checks do not replace a screen-reader user study. Local lab measurements are single unthrottled observations, not field Core Web Vitals.
