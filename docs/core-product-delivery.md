## What the user can do

Choose supported relationship files and compare immediately without entering an account username/date or confirming completeness. The default category is **Not following you back**, with the supplied-file scope statement. Search, safe profile links, pagination and full-category CSV/dataset exports remain available. No account-count cap hides later records. Optional metadata and local snapshot controls are collapsed.

JSON relationship variants, harmless optional fields, BOM/profile-URL identities, inert HTML, loose/split files, nested export folders, multiple ZIPs and validated MutualLens dataset exports are supported within documented safety budgets. Ambiguous loose files request a followers/following assignment. A missing whole direction is an actionable error; recognized empty lists are valid. Known skipped/quarantined rows or missing numbered parts produce usable provisional differences and limitations in exports. A failed replacement import preserves the current report.

ZIP processing uses bounded metadata and slices; it reads/decompresses selected relationship documents without loading irrelevant media. ZIP64, encrypted/split-volume archives and unsupported compression remain explicit unsupported cases. See [format details](core-formats.md). These compatibility checks use structural synthetic fixtures; no previously rejected private owner export was supplied to this pass.
